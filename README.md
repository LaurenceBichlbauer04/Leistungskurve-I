# Leistungskurve-I
von Laurence Bichlbauer und Jan Arnsteiner


Dieses Projekt liest Laufdaten aus einer CSV-Datei ein, sortiert die Leistungswerte und erstellt daraus eine Leistungskurve als Abbildung.

## Voraussetzungen

- Python 3.14+
- pip

## Projekt installieren

Repository klonen:

```bash
git clone <REPOSITORY-URL>
cd Leistungskurve-I
```
Virtuelle Umgebung erstellen:
```bash
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
Datei ausführen:
```bash
python main.py

```
